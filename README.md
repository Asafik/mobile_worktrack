# Biustechno Mobile Companion (WorkTrack)

Aplikasi mobile companion untuk platform WorkTrack / Biustechno, dibangun menggunakan React Native dan Expo.

## Fitur Utama
- **Beranda (Dashboard)**: Statistik proyek, penyelesaian tugas, progress bar, dan catatan terbaru yang tersinkronisasi real-time.
- **Notes**: Manajemen catatan, kategori, status sematan (pin), dan perapian teks otomatis menggunakan Gemini AI.
- **Tasks**: Manajemen tugas dengan live search proyek, filter status (Belum Selesai, Selesai, Semua), dan prioritas.
- **Real-time Sync**: Terhubung langsung ke Supabase database.
- **Standalone Android APK**: Dikonfigurasi untuk EAS Build dengan package ID `com.biustechno.app`.

## Menjalankan Proyek
```bash
# Install dependencies
npm install

# Menjalankan Expo development server
npx expo start
```
